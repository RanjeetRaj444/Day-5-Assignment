 ## 📁 Folder Structure 
```swift

├── index.html               // Main character gallery
├── character.html           // Character detail page
├── css/
│   └── styles.css
├── js/
│   ├── main.js              // Handles gallery view and pagination
│   └── detail.js            // Handles character detail fetch/display
├── assets/
│   └── icons/, fonts/, etc.
├── README.md

```

## 🚀 Features

- Character grid (3x2)
- Pagination (Next/Prev)
- Live footer clock
- Detailed character view in new tab
- Dark/Light mode (optional)
- Random character button (optional)

